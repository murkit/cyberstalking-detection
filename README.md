# Виявлення кіберсталкінгу в українськомовних текстах
Проєкт присвячений розробці та оцінюванню моделей машинного навчання для автоматизованого виявлення кіберсталкінгу в українськомовних текстових повідомленнях.
Мета проєкту - сприяти підвищенню безпеки користувачів у цифровому середовищі шляхом виявлення повідомлень, які можуть містити ознаки кіберпереслідування. Система виконує бінарну класифікацію повідомлень і визначає тип кіберсталкінгу, якщо його виявлено.
Реалізовано мовою Python із використанням бібліотеки scikit-learn.

Розроблено в межах випускної кваліфікаційної роботи, присвяченої виявленню кіберсталкінгу в українськомовному цифровому середовищі, тож більше про кіберсталкінг, обґрунтування обраних методів, проєктування повноцінної системи виявлення загрози можна прочитати за посиланням:
**[Дипломна робота: «Розробка застосунку для автоматизованого виявлення кіберсталкінгу»]([ВСТАВТЕ_ПОСИЛАННЯ_НА_ДИПЛОМ](https://rkr.op.edu.ua/16196))**

## Актуальність

Кіберсталкінг - це форма переслідування людини з використанням цифрових засобів комунікації. Він може проявлятися у вигляді погроз, залякування, нав'язливої уваги, маніпуляцій або повідомлень із сексуальним підтекстом. Автоматизований аналіз текстів може допомогти виявляти потенційно небезпечні повідомлення та зменшувати потребу в їх первинному ручному перегляді.

## Мета та завдання

Мета: розробити та оцінити модель машинного навчання для автоматизованого виявлення ознак кіберсталкінгу в українськомовних текстах.
Основні завдання:
- підготувати та очистити текстовий набір даних;
- перетворити текстові повідомлення на числові ознаки за допомогою TF-IDF;
- побудувати бінарну модель для виявлення кіберсталкінгу;
- побудувати багатокласову модель для визначення типу кіберсталкінгу;
- налаштувати гіперпараметри за допомогою GridSearchCV;
- оцінити якість моделей;
- проаналізувати помилки.

## Набір даних

Для навчання та оцінювання моделей використовується підготовлений набір українськомовних текстових повідомлень.
У межах роботи з даними виконуються очищення тексту, перевірка міток класів, обробка пропущених і порожніх записів, а також перевірка дублікатів.
Набір даних містить повідомлення, розмічені за наявністю кіберсталкінгу та його типом. У формуванні датасету використовувалися синтетичні повідомлення та повідомлення, перекладені з англомовних джерел, відповідно до опису дослідження.

## Попередня обробка даних

Перед навчанням моделей текст проходить попередню обробку, спрямовану на зменшення шуму та забезпечення узгодженості ознак.
Основні етапи:
1. Застосовується Unicode-нормалізація, текст приводиться до нижнього регістру.
2. Посилання й згадки замінюються спеціальними токенами.
3. Зайві символи та пунктуація видаляються, пробіли нормалізуються.
4. Записи без необхідного тексту або міток виключаються з відповідних вибірок.
5. Категорії перетворюються на числові значення, необхідні для навчання моделей.
6. Однакові очищені тексти перевіряються на суперечності в мітках.
7. TF-IDF перетворює очищені тексти на числові вектори.

## Архітектура класифікації

У проєкті реалізовано каскадний підхід, який складається з двох моделей.

### 1. Бінарна класифікація

Перша модель визначає, чи містить повідомлення ознаки кіберсталкінгу.

| Мітка | Клас |
|---|---|
| `0` | Cyberstalking |
| `1` | No-Cyberstalking |

### 2. Багатокласова класифікація

Якщо перша модель визначає повідомлення як кіберсталкінг, друга модель прогнозує його тип.

| Мітка | Клас |
|---|---|
| `0` | Intimidation - залякування |
| `1` | Ordinary - звичайний кіберсталкінг |
| `2` | SexualHarassment - сексуальні домагання |

Обидві моделі використовують TF-IDF для представлення тексту та LinearSVC для класифікації. Для врахування можливого дисбалансу класів застосовується `class_weight="balanced"`.
Для підбору параметра регуляризації `C` використовується GridSearchCV із п'ятикратною груповою стратифікованою крос-валідацією.

## Методологія оцінювання

Якість моделей оцінюється на окремій тестовій вибірці - 20% датасету. Основним критерієм підбору параметрів є Macro-F1.
Для оцінювання використовуються такі метрики:
- Accuracy - частка правильно класифікованих прикладів.
- Precision - частка правильних передбачень певного класу серед усіх передбачень цього класу.
- Recall - частка правильно виявлених прикладів певного класу.
- F1-score - гармонійне середнє Precision і Recall.
- Macro-F1 - середнє значення F1-score для всіх класів з однаковою вагою кожного класу.
- Weighted-F1 - середнє значення F1-score з урахуванням кількості прикладів кожного класу.
- ROC-AUC - оцінка здатності моделі розрізняти класи за різних порогів класифікації.

Для аналізу помилок використовуються матриці помилок. Для багатокласової моделі ROC-AUC оцінюється з використанням підходу One-vs-Rest.

## Результати моделей

Наведені нижче результати отримано на тестовій вибірці з 2692 повідомлень для бінарної моделі та наскрізної каскадної системи. Багатокласова модель оцінювалася на 1553 повідомленнях, що належать до класу кіберсталкінг.

| Модель | Кількість тестових прикладів | Accuracy | Macro Precision | Macro Recall | Macro-F1 | ROC-AUC |
|---|---:|---:|---:|---:|---:|---:|
| Бінарна SVM | 2 692 | 0.9859 | 0.9857 | 0.9854 | 0.9855 | 0.9945 |
| Багатокласова SVM | 1 553 | 0.9021 | 0.9031 | 0.9018 | 0.9024 | 0.9611 |
| Каскадна система | 2 692 | 0.9302 | 0.9147 | 0.9147 | 0.9147 |   |

ROC-AUC для багатокласової моделі наведено як Macro ROC-AUC. Для каскадної системи цей показник у поточному експерименті не обчислювався.

### Результати крос-валідації

| Модель | Найкраще значення `C` | CV Macro-F1 |
|---|---:|---:|
| Бінарна SVM | 10 | 0.9723 |
| Багатокласова SVM | 10 | 0.8477 |

Результати показують високу якість бінарної класифікації та дещо складніше завдання для моделі, яка визначає конкретний тип кіберсталкінгу.

## Порівняння GridSearchCV та Optuna

Для пошуку ефективної конфігурації моделей було проведено два експерименти.

Базовий підхід - GridSearchCV
Перевірялися задані значення параметра регуляризації `C`, а найкраща конфігурація обиралася за Macro-F1 під час крос-валідації.

Додатковий експеримент - Optuna
Досліджувалися різні значення `C`, кількість текстових ознак, параметр `min_df` і тип n-грам.

### Порівняння результатів на тестовій вибірці

| Задача | Метод | Accuracy | Macro-F1 |
|---|---|---:|---:|
| Бінарна класифікація | GridSearchCV | **0.9859** | **0.9855** |
| Бінарна класифікація | Optuna | 0.9840 | 0.9836 |
| Класифікація типів | GridSearchCV | **0.9021** | **0.9024** |
| Класифікація типів | Optuna | 0.9008 | 0.8996 |

У проведених експериментах базові моделі з підбором параметра `C` за допомогою GridSearchCV продемонстрували дещо кращі результати на тестовій вибірці, ніж конфігурації, вибрані Optuna.
Для бінарної класифікації Macro-F1 становив 0.9855 для GridSearchCV і 0.9836 для Optuna. Для класифікації типів кіберсталкінгу результати становили 0.9024 і 0.8996 відповідно.
Тому для фінальної версії проєкту було обрано базові моделі з GridSearchCV.

## Аналіз перенавчання

Для додаткового оцінювання узагальнювальної здатності моделей було порівняно показники на навчальній і тестовій вибірках.

| Модель | Train Macro-F1 | Test Macro-F1 | Різниця |
|---|---:|---:|---:|
| Бінарна SVM | 0.9995 | 0.9855 | 0.0140 |
| Багатокласова SVM | 0.9858 | 0.9024 | 0.0833 |

Бінарна модель демонструє невеликий розрив між навчальними та тестовими показниками. Для багатокласової моделі розрив більший, що вказує на можливе перенавчання, тож потребу попрацювати над якістю даних і якості самої моделі в майбутніх дослідженнях.

## Подальший розвиток

- розширення та покращення балансу датасету, бажано на реальних даних, можливо збільшення типів сталкінгу;
- дослідження самого явища кіберсталкінгу для кращого визначення його ознак;
- дослідження альтернативних методів векторизації та класифікації, або інших методів ml в цілому на прикладі кіберсталкінгу.

### Висновок

У проведених експериментах бінарна SVM-модель показала високу якість виявлення потенційних ознак кіберсталкінгу. Бінарна модель має Accuracy 0.9859, Macro-F1 - 0.9855. Багатокласова модель забезпечила Accuracy 0.9021, Macro-F1 0.9024, а повна каскадна система - Accuracy 0.9302, Macro-F1 0.9147 на тестовій вибірці.
Ці результати свідчать про перспективність використання TF-IDF та SVM для аналізу українськомовних текстів на наявність кіберсталкінгу.
